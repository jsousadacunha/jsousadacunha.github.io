# Hit-o-matic

## 1. Objeto y aceptación
Bienvenido a Hit-o-matic, una aplicación desarrollada por PuzumaSoft. Al utilizar esta aplicación, aceptas estas Condiciones Generales de Utilización (CGU). Si no estás de acuerdo, por favor no uses la aplicación.

## 2. Condiciones de uso
El uso de Hit-o-matic es gratuito y no implica coste alguno para el usuario. La aplicación no ofrece garantías ni asume responsabilidad por errores, interrupciones o incompatibilidades.

## 3. Requisitos previos
Para utilizar Hit-o-matic, debes:
- Tener una cuenta Premium de Spotify.
- Tener instalada la aplicación oficial de Spotify en el mismo dispositivo.

## 4. Privacidad y tratamiento de datos
Hit-o-matic utiliza las API de Spotify para recuperar ciertos datos del usuario y permitir la reproducción remota. Ningún dato personal se almacena ni se envía a servicios externos; se usan únicamente de forma local. Para saber cómo Spotify gestiona tus datos, consulta sus CGU.
Los únicos datos recogidos por Hit-o-matic son técnicos, con fines estadísticos y para corregir errores:
- Tipo de dispositivo.
- Versión del sistema operativo.
- Registros de errores (logs).
- Estadísticas de uso.
